# Testes de QA — Cozinha IA

## Sobre o projeto

Projeto de testes de um agente de IA responsável por fornecer
receitas culinárias a partir de um acervo previamente definido.

## Atividades realizadas

- Análise do escopo e regras de negócio
- Elaboração de cenários e casos de teste
- Execução de testes
- Registro dos resultados obtidos
- Identificação de comportamentos inesperados
- Registro de bugs
- Avaliação de gravidade
- Documentação das evidências
